Arquitetura de componentes

Atoms → buttons, inputs, labels, icons. Molecules → search, byline, pagination, breadcrumb, tabs. Organisms → cards, navbar, mega menu, sidebar, footer, ad slots. Every component uses variants, properties, Auto Layout and Claro/Escuro semantic tokens.
